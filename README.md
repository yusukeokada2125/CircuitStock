# CircuitStock

## 概要

電子工作・電子回路設計を学習する個人利用者向けの、電子部品在庫管理・試作記録アプリケーションです。

電子部品の在庫や保管場所を管理するとともに、
試作の内容、使用した部品や製作時の課題、改善点、完成写真などを記録し、学習の振り返りを支援することを目的としています。

---

## 開発背景

電子工作では、部品数が増えるにつれて在庫状況や保管場所の把握が難しくなり、同じ部品を重複して購入したり、必要な部品を探すのに時間がかかることがあります。

また、製作過程で得られた知見や失敗、改善点を記録する手段が少なく、同じ失敗を繰り返してしまうことがあります。

CircuitStockは、

- 電子部品の在庫管理
- 学習記録
- 試作記録

を一つのアプリで管理できることを目指して開発しています。

# データベース管理項目

## ユーザー

### 利用場面
- ユーザー登録
- ログイン
- ログアウト
- ログイン後のユーザー識別

### 必要な情報
- メールアドレス
→ 次回ログイン時にも照合するため保存が必要
- パスワード
→ 認証に必要なため、継続的に保持する必要がある
- ユーザーID
→ ユーザーそのものを一意に識別するため
- ユーザー名
→ ログイン後にユーザーを表示・識別するため


### MVPで必要
- ユーザーID
- ユーザー名
- メールアドレス
- パスワード

### MVPでは管理しない
- プロフィール画像
- 自己紹介
- ニックネーム
- 最終ログイン日時
- 利用設定

## 部品
 
### 利用場面 
- 部品の登録 
- 部品の変更
- 部品の削除
- 部品の検索・絞り込み
 
### 必要な情報 
- 部品ID 
→ 部品を一意に識別するため 
- 製品名
→ 部品を表示・識別し、検索に使用するため
- 型番
→ 部品の型番・製造上の識別情報を管理するため
- カテゴリ
 → 部品がどのカテゴリに属するかを管理し、絞り込みに使用するため
- 保管場所
 → 部品がどこに保管されているかを管理し、絞り込みに使用するため
- 在庫数
→ 現在保持している部品数を管理・表示するため

### MVPで必要 
- 部品ID 
- 製品名
- 型番
- カテゴリ
- 保管場所
- 在庫数

### MVPでは管理しない 
- 部品のメーカー名
- 部品のスペック情報
- 部品をさらに分類する上位部品・種別



## 入出庫履歴
 
### 利用場面 
- 入庫の登録、いつ・どの部品が、どれだけ、なぜ増加したか記録する
- 出庫の登録、いつ・どの部品が、どれだけ、なぜ減少したか記録する
- 入出庫履歴の検索・絞り込み
 
### 必要な情報 
- 入出庫ID
→ 入出庫履歴を一意に識別するため
- 作成日時
→ いつ入庫・出庫をしたか記録するため
- 部品ID
→ 対象となる部品を識別し、検索に使用するため
- 入出庫区分
→ 入庫か出庫を識別し、在庫数を増加・減少させる処理を判断するため
- 数量
→ どれだけ在庫数を増加・減少させるかを管理・表示するため
- 備考
→ なぜ在庫数が変動したか理由を管理・表示するため


### MVPで必要 
- 入出庫ID
- 作成日時
- 部品ID 
- 入出庫区分
- 数量
- 備考

### MVPでは管理しない 
- なし

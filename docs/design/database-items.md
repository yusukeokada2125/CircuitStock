# データベース管理項目

## ユーザー

### 利用場面
- ユーザー登録
- ログイン
- ログアウト
- ログイン後のユーザー識別

### 必要な情報
- メールアドレス
→ 次回ログイン時にも照合するため保存が必要
- パスワード
→ 認証に必要なため、継続的に保持する必要がある
- ユーザーID
→ ユーザーそのものを一意に識別するため

### MVPで必要
- ユーザーID
- メールアドレス
- パスワード

### MVPでは管理しない
- プロフィール画像
- 自己紹介
- ニックネーム
- 最終ログイン日時
- 利用設定



## カテゴリ
 
### 利用場面 
- カテゴリの登録 
- カテゴリの変更
- カテゴリの削除
- 部品管理画面からカテゴリの検索・絞り込み
 
### 必要な情報 
- カテゴリID 
→ カテゴリを一意に識別するため 
- カテゴリ名
→ 登録後にカテゴリを表示・識別する
 
### MVPで必要 
- カテゴリID
- カテゴリ名
 
### MVPでは管理しない 
- 部品カテゴリをさらに分類する上位カテゴリ・種別

# 画面遷移

## MVPで必要な画面の確認

### 認証

- ログイン操作
→ メールアドレスとパスワードを入力する
- 必要な画面
→ ログイン画面

- ログアウト操作
→ ログイン後の画面のヘッダー等にあるユーザーアイコンからログアウト
- ログアウト画面
→ 不要


### カテゴリ

- カテゴリ登録の操作
→ 新規カテゴリを登録する
- 専用画面
→ カテゴリ管理画面

- カテゴリ変更の操作
→ 登録済みカテゴリ名を変更する
- 専用画面
→ カテゴリ管理画面

- カテゴリ削除の操作
→ 使用中のカテゴリであれば、先に対象部品のカテゴリを変更する
→ その後、カテゴリそのものを削除する
- 専用画面
→ カテゴリ管理画面

- カテゴリ検索・絞り込みの操作
→ カテゴリから部品を探す、絞り込みをする
- 専用画面
→ 不要、部品管理画面で行う


### 保管場所

- 保管場所登録の操作
→ 新規保管場所を登録する
- 専用画面
→ 保管場所管理画面

- 保管場所名変更の操作
→ 登録済み保管場所名を変更する
- 専用画面
→ 保管場所管理画面

- 保管場所削除の操作
→ 使用中の保管場所であれば、先に対象部品の保管場所を変更する
→ その後、保管場所そのものを削除する
- 専用画面
→ 保管場所管理画面

- 保管場所の検索・絞り込みの操作
→ 保管場所から部品を探す、絞り込みをする
- 専用画面
→ 不要、部品管理画面で行う


### 部品

- 部品登録の操作
→ 新規部品を登録する
- 専用画面
→ 部品登録・編集画面

- 部品情報変更の操作
→ 登録済みの部品情報を変更する
- 専用画面
→ 部品登録・編集画面

- 部品削除の操作
→ 登録済みの部品を物理削除
→ 登録済みの部品を論理削除
※部品管理の条件に従う 
- 専用画面
→ 部品詳細画面または部品管理画面から行うか検討

- 部品の一覧を見る操作 
→ 部品のカテゴリ、保管場所、在庫数などの情報を一覧で見る
→ 部品の詳細画面へ遷移する
- 専用画面
→ 部品管理画面

- 部品の詳細情報を見る操作 
→ 部品の詳細情報を確認する
→ 必要に応じて部品編集や入出庫などの操作へ進む
- 専用画面
→ 部品詳細画面

- 部品検索・絞り込みの操作
→ 部品の一覧から検索・絞り込みをする
- 専用画面
→ 部品管理画面


### 在庫

- 現在在庫数を確認する操作
→ 部品管理画面の一覧表示から在庫数を確認
→ 部品詳細画面の詳細情報から在庫数を確認
- 専用画面
→ 不要、部品管理画面と部品詳細画面

- 在庫検索・絞り込みの操作
→ 在庫数を条件に部品を検索・絞り込みする 
- 専用画面
→ 不要、部品管理画面

- 在庫数を入出庫によって変更する操作
→ 入庫・出庫の登録によって在庫数を増減する 
- 専用画面
→ 不要、部品詳細画面から入出庫管理画面へ遷移


### 入出庫

- 入庫・出庫を登録する操作
→ いつ、どの部品を、入庫または出庫したか、数量、増減理由を登録する 
- 専用画面
→ 入出庫登録画面

- 部品ごとの入出庫履歴を確認する操作
→ 部品ごとの過去の入出庫を履歴として確認する
- 専用画面
→ 不要、部品詳細画面

- 全体の入出庫履歴を確認する操作
→ 入出庫履歴を時系列で一覧表示し、部品・入出庫区分・日付などで絞り込みを行う
- 専用画面
→ 入出庫履歴画面

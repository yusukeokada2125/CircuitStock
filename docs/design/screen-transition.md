# 画面遷移

## MVPで必要な画面の確認

### 認証

- ログイン操作
→ メールアドレスとパスワードを入力する
- 必要な画面
→ ログイン画面

- ログアウト操作
→ ログイン後の画面のヘッダー等にあるユーザーアイコンからログアウト
- ログアウト画面
→ 不要


### カテゴリ

- カテゴリ登録の操作
→ 新規カテゴリを登録する
- 専用画面
→ カテゴリ管理画面

- カテゴリ変更の操作
→ 登録済みカテゴリ名を変更する
- 専用画面
→ カテゴリ管理画面

- カテゴリ削除の操作
→ 使用中のカテゴリであれば、先に対象部品のカテゴリを変更する
→ その後、カテゴリそのものを削除する
- 専用画面
→ カテゴリ管理画面

- カテゴリ検索・絞り込みの操作
→ カテゴリから部品を探す、絞り込みをする
- 専用画面
→ 不要、部品管理画面で行う


### 保管場所

- 保管場所登録の操作
→ 新規保管場所を登録する
- 専用画面
→ 保管場所管理画面

- 保管場所名変更の操作
→ 登録済み保管場所名を変更する
- 専用画面
→ 保管場所管理画面

- 保管場所削除の操作
→ 使用中の保管場所であれば、先に対象部品の保管場所を変更する
→ その後、保管場所そのものを削除する
- 専用画面
→ 保管場所管理画面

- 保管場所の検索・絞り込みの操作
→ 保管場所から部品を探す、絞り込みをする
- 専用画面
→ 不要、部品管理画面で行う
